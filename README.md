# Dorsal

**Team Dorsal** · 2026 Shenzhen International FinTech Competition (FinTechathon), International Track · Topic E: SME Finance Copilot

Dorsal is an AI cash-flow copilot for small businesses. It forecasts the next 13 weeks of cash as a range of possible
futures, finds the gaps, and acts to close them (chasing late payers, catching duplicate bills, arranging the cheapest
suitable financing), but only inside permission tiers the owner controls.

> **Why "Dorsal"?** A shark's dorsal fin keeps an apex predator stable at full speed. Dorsal does the same for a small
> business's cash.

## How this project is being built

The initial implementation of Dorsal was generated with an AI coding assistant on 12 October 2026, following the
problem definition, product direction, requirements and brand set by Team Dorsal. AI-assisted development has been
confirmed as permitted by the organizers.

From 12 to 16 October 2026, Team Dorsal is reviewing, testing and integrating the code **module by module** in this
repository, learning each part and making changes along the way. Each commit message states which module was added and
what was reviewed. The full README, setup instructions and documentation arrive in later commits.
